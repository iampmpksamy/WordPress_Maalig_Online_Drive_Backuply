# Support

Use [GitHub Issues](https://github.com/iampmpksamy/WordPress_Maalig_Online_Drive_Backuply/issues) for reproducible bugs and development requests.

Include:

- WordPress and PHP versions
- Site size and available disk space
- PHP memory and execution-time limits
- Steps to reproduce the problem
- Sanitized plugin and PHP logs

Never attach database exports, backup archives, credentials, OAuth tokens, client secrets, personal information, or unredacted production logs.
